# ReadRelay Homebrew tap

Install the Apple silicon macOS beta.

```fish
brew install ankitgoyalio/readrelay/readrelay
readrelay --version
```

The [ReadRelay beta guide](https://github.com/ankitgoyalio/readrelay/blob/v0.1.0/README.md) walks through mailbox setup, preview, and recurring sync. The [GitHub Releases](https://github.com/ankitgoyalio/readrelay/releases) page lists available builds and verification results.
